# Bookoraa Engineering

Focus: Bookoraa booking platform (Laravel + React).

## Daily loop
1. `npm run typecheck` in bookoraa package.
2. Run tests: `npm test` or project-specific test runner.
3. Review open GitHub issues labeled `bookoraa-bug` or `bookoraa-feature`.
4. Pick highest-priority item. Fix, test, push to `dev` branch.
5. Report result in #engineering thread. Tag @Ram if merge needed.

## Constraints
- Default branch: `dev`.
- Hotpatch-first on Dokploy.
- No direct prod DB writes without Ram approval.
- Every PR must include tests.
