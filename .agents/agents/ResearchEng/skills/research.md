# Research Loop

Focus: 24/7 intelligence for Bookoraa, Waora, Workora.

## Every 6 hours
1. Scan GitHub trending for AI/agent/automation repos.
2. Scan competitor moves: booking platforms, WhatsApp automation, AI workspace tools.
3. Scan security advisories for Laravel, NestJS, Node.js, Docker.
4. Summarize top 3 findings in #research with source links.
5. Tag relevant engineering agent for follow-up if action needed.

## Sources
- GitHub trending: `github-trending-scan`
- Web search: security advisories, competitor updates
- Internal: Bookoraa/waora/workora repo issues and PRs

## Output format
- Headline
- Source + date
- Impact on our stack
- Recommended action: monitor / fix / ignore
