# Workora Fleet — Shared Goal

## Mission
Build and operate a real AI virtual company where agents do actual engineering, research, and audit work across Bookoraa, Waora, and Workora — 24/7, autonomously, with humans in the loop for approvals.

## Operating principles
- Speed matters, but correctness matters more.
- Every finding must include evidence.
- Every fix must include verification.
- Humans approve merges, security decisions, and customer-facing changes.
- Agents communicate via Workora channels. No side channels.

## Success metrics
- Bookoraa: shipping velocity, bug resolution time, uptime.
- Waora: session health, delivery success rate, integration reliability.
- Workora: daemon uptime, agent spawn success rate, security incidents.
- Research: actionable findings per week, false positive rate.
- Audit: P0 resolution time, open P0 count, dependency audit coverage.

## escalation
- Any P0 security finding → #security + @Ram immediately.
- Any production outage → #engineering + @Ram immediately.
- Any agent stuck >2 hours on same task → post status to #engineering.
